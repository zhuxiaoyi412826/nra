# 射击小游戏（Web）

一个基于 Canvas 的俯视角射击网页小游戏，技术栈为 HTML + CSS + JavaScript（无框架）。  
 - 游戏名： 霓虹夜袭
- 英文简称： NRA （Neon Raid Assault）

## 快速开始

- 直接用浏览器打开 [index.html](file:///d:/1/%E5%B0%84%E5%87%BB%E5%B0%8F%E6%B8%B8%E6%88%8F/index.html) 即1可运行（建议 Chrome / Edge）。

## 操作说明

### PC

- 移动：WASD / 方向键
- 瞄准：鼠标
- 射击：鼠标左键（按住连续射击，取决于武器）
- 换弹：F
- 打开/关闭商店：B
- 暂停：Esc
- 切换武器：数字 1/2/3/4/5（武器槽）
- 快捷切换：9（重型机枪 HMG）
- 特殊武器：Q 手雷 / E 火箭筒 / R 雷暴

### 手机（触屏）

- 左下虚拟摇杆移动
- 右侧按钮射击/换弹/切枪/暂停/商店
- 在画布区域滑动用于调整瞄准方向

## 已实现功能汇总

### 画面与表现

- 像素风渲染：高分辨率绘制 → 降采样 → 放大，关闭平滑并启用 pixelated 显示 (混合 Konva.js 与原生 Canvas 2D 绘图管线)
- 动画系统：基于三角函数与时间戳的纯数学动态骨骼动画（Skeletal Animation），实现真实的迈腿、摆臂、躯干起伏
- 粒子特效：枪口火花/烟、命中血花、击杀爆散、受伤溅射、爆炸烟尘、电火花等
- 贴花系统（Decals）：地表永久血迹与战斗痕迹，内置 20 秒 TTL 自动淡出回收机制
- 小地图：显示玩家、敌人、障碍物、掉落物、视野框与瞄准方向
- 昼夜变化：夜晚氛围与视效叠加

### 核心玩法

- 玩家：移动、战术翻滚（带无敌帧与尾迹）、瞄准、射击、切枪、换弹
- 敌人：多类型 AI（基础/快速/坦克/远程）+ 精英敌人（更强属性与明显外观）
- BOSS 体系：按击杀阈值刷出，包含阶段（血量 50% 或 30% 以下狂暴）与技能循环
  - 灾厄核心（Core）：弹幕环射 / 冲刺突进 / 召唤小怪 / 爆发新星
  - 亡命枪手（Gunslinger）：霰弹扫射 / 火箭狙击 / 战术翻滚 / 召唤小怪
  - 火焰巨人（Fire Giant）：火焰刀 / 火焰球 / 火焰吐息 / 地面重击
  - 幽影咒主（Morphila）：暗影咒缚 / 追踪幽影弹幕 / 巨大暗域侵蚀 / 终极暗影湮灭 (Konva.js 绘制)
- 特殊武器（实体化装备）：Q 手雷 / E 火箭筒 (带独立后坐力/装填动画) / R 雷暴枪（带独特弹道与爆炸范围效果）

### UI 与系统

- 菜单：现代化玻璃拟态 (Glassmorphism) 主界面、设置面板、死亡结算
- HUD：生命/饥饿/口渴、弹药、击杀、金币/钻石、任务、时间与昼夜、BOSS 血条
- 增益显示：购买升级后 toast 提示 + HUD 增益面板（生命/移速/伤害倍率等）
- 商店系统：可购买补给、升级、武器（新增武器槽）
- 本地排行榜：基于 localStorage

### 音效

- WebAudio 合成音效（无需外部音频资源）
- 事件覆盖：射击（按武器区分）、换弹、空仓、命中、受伤、拾取、UI、精英/ BOSS 提示等

## 武器清单

- 常规武器：手枪、步枪、霰弹枪、冲锋枪（SMG）、连发步枪（DMR）、狙击枪（Sniper）
- 重型机枪：HMG（数字 9 快捷切换）

## 微信小游戏改造方案（摘要）

结论：可以迁移到微信小游戏。总体思路是“核心层复用 + 平台层适配”。

- 核心差异：微信小游戏没有标准 DOM/HTML，依赖 `wx.createCanvas()` 与 `wx.*` API
- 建议拆分：
  - 核心层（纯逻辑）：世界/实体/碰撞/武器/BOSS/状态机，不依赖 DOM
  - 平台层（适配）：渲染、输入、音频、存储、生命周期
- UI 迁移：DOM 商店/按钮 → Canvas UI（命中测试触发购买/切枪）
- 存储迁移：`localStorage` → `wx.setStorageSync/getStorageSync`（好友排行再做开放数据域）
